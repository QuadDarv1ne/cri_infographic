## О проекте

**CRI и Цветовая температура** — интерактивная веб-инфографика, посвящённая индексу цветопередачи (CRI) и цветовой температуре света. Проект позволяет наглядно изучить, как различные источники света влияют на восприятие цветов, и содержит интерактивные визуализации, сравнительные таблицы и квиз для проверки знаний.

Информация основана на ГОСТ 54350-2015.

## Разделы инфографики

| # | Раздел | Описание |
|---|--------|----------|
| 1 | **Шкала CRI** | Интерактивный ползунок CRI с визуальной шкалой и предпросмотром помещения |
| 2 | **Где важен высокий CRI** | Карточки с областями применения, где качество цветопередачи критично |
| 3 | **Типы источников света** | Сравнение ламп накаливания, люминесцентных, светодиодных и др. по CRI и температуре |
| 4 | **Цветовая температура** | Интерактивный циферблат цветовой температуры с визуализацией тона света |
| 5 | **Диапазоны цветовой температуры** | Таблица основных диапазонов (тёплый, нейтральный, холодный) и их применение |
| 6 | **Восприятие цветов** | Сетка цветов, показывающая влияние цветовой температуры на оттенки |
| 7 | **Сравнение источников света** | Настройка параметров двух источников и сравнение цветопередачи |
| 8 | **Квиз** | 5 вопросов для проверки знаний о CRI и цветовой температуре |

## Возможности

- **Интерактивная шкала CRI** с визуальной обратной связью в реальном времени
- **Предпросмотр помещения** — как меняется восприятие интерьера при разных параметрах света

## Установка и запуск

### Предварительные требования

- **Node.js** версии 18 или выше (рекомендуется 20+)
- **bun** (рекомендуется) или npm/yarn/pnpm

### Установка

```bash
# Клонировать репозиторий
git clone https://github.com/your-username/cri_infographic.git
cd cri_infographic

# Установить зависимости
bun install

# Запустить в режиме разработки
bun run dev
```

Приложение будет доступно по адресу [http://localhost:3000](http://localhost:3000).

### Сборка для продакшена

```bash
# Сборка проекта
bun run build

# Запуск собранного приложения
bun run start
```

## Конфигурация

### База данных

По умолчанию используется SQLite (файл `prisma/dev.db`). Поддерживаются также PostgreSQL и MySQL. Выберите БД через `DATABASE_URL` в `.env`:

| База данных | `DATABASE_URL` |
|-------------|----------------|
| **SQLite** (по умолчанию) | `file:./dev.db` |
| **PostgreSQL** | `postgresql://user:pass@localhost:5432/cri_infographic` |
| **MySQL** | `mysql://user:pass@localhost:3306/cri_infographic` |

Команды для работы с БД:

```bash
bun run db:generate  # Сгенерировать клиент Prisma
bun run db:push      # Применить схему к БД
bun run db:migrate   # Создать и применить миграцию
```
